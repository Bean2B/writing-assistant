# 版本记录 / Changelog

## 中文

### 0.1.1

由 AI 驱动、由 Codex 开发的写作应用，主要由 Agent 在 user 的授权内操作。

- 保存灵感、设定和草稿，保留原文字节、准确版本、检索与书签。
- 明确发起 Codex 写作、返修、稿件审读与有上限的故事推演。
- 保存章节 workflow、准确 task 依赖、审读决定和中断恢复状态。
- 管理有证据的故事状态，明确选择内置的版本化技法。

生成结果由 user 取舍，不会自动采用。界面、运行要求与限制见 [Agent 接入说明](docs/agent-usage.md)、[使用指南](docs/usage.md)和 [Codex 支持](docs/codex-support.md)。

## English

### 0.1.1

An AI-powered writing application developed by Codex, primarily operated by Agents within the user's authorization.

- Preserve ideas, settings and drafts with original bytes, exact versions, search and bookmarks.
- Explicitly execute Codex writing, revision, draft review and bounded story exploration.
- Save chapter workflows, exact task dependencies, review decisions and interruption recovery state.
- Manage evidence-bound story state and explicitly select versioned built-in techniques.

The user decides which generated results to adopt; adoption is never automatic. See [Agent usage](docs/agent-usage.md), [usage](docs/usage.md) and [Codex support](docs/codex-support.md) for interfaces, requirements and limits.
