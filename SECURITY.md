# Security and privacy / 安全与隐私

书稿和本地书库可能含有私人信息。发布 issue 时仅使用虚构的最小示例。请勿上传凭据、实际书稿、完整日志或读者身份信息。只有明确执行已配置的模型任务，才会将其选定的内容发送给提供商。请保护应用所在目录和本机账户。

Use synthetic examples for public issue reports. Keep credentials, manuscripts, reader identities and full logs out of public reports. A local book directory grants its owner access to the underlying manuscripts and notes. Review the exact material before dispatching a model task. See [operations](docs/operations.md) and [model tasks](docs/task-runtime.md).
