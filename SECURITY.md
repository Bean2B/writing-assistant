# 安全问题 / Security reports

[中文](#中文) · [English](#english)

## 中文

请在 [Issues](https://github.com/Bean2B/writing-assistant/issues) 用虚构数据说明可复现的
问题。Issues 公开可见，请勿附上凭据、真实稿件、个人信息或原始诊断包，只提供可以
公开的复现例子。公开 repo 不接收 PR。

## English

Report reproducible problems in [Issues](https://github.com/Bean2B/writing-assistant/issues)
using made-up data. Issues are public: leave out credentials, manuscripts,
personal information, and raw diagnostic bundles. Share only a reproduction
that is safe to make public. This public repository does not accept PRs.
