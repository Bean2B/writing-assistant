# 第三方工具 / Third-party tools

[中文](#中文) · [English](#english)

## 中文

Writing Assistant 使用 Python 标准库，没有第三方 Python runtime 依赖。以下工具需要单独安装：

| 工具 | 用途 |
| --- | --- |
| [Python](https://www.python.org/) 3.12 | 运行应用与构建安装包。 |
| [pip](https://pip.pypa.io/) | 构建和安装 Python package。 |
| Codex CLI | 使用既有登录执行 AI 任务；版本要求见 [Codex 支持](docs/codex-support.md)。 |

安装包不附带这些工具或登录凭据。外部工具及其服务保留各自的许可证和条款；本项目的 [Apache-2.0 许可证](LICENSE)不替代它们的条款。

## English

Writing Assistant uses the Python standard library and has no third-party Python runtime dependencies. Install these tools separately:

| Tool | Purpose |
| --- | --- |
| [Python](https://www.python.org/) 3.12 | Run the application and build packages. |
| [pip](https://pip.pypa.io/) | Build and install Python packages. |
| Codex CLI | Run AI tasks with existing authentication; see [Codex support](docs/codex-support.md#english) for accepted versions. |

Packages do not include these tools or authentication data. External tools and services retain their own licenses and terms; this project's [Apache-2.0 license](LICENSE) does not replace them.
