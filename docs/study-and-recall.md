# Source study and author recall

All examples below follow `scripts/writing-assistant --book DIR`. The source-study tables and author’s scene index belong to the selected book. The coordinator owns DB access and forwards only the assigned output to each session.

## Studying a source

Decide what the supplied text contributes. Extract creative requirements into the book's settings, outline or author notes. Preserve original wording only for passages used as literary or factual evidence. If a character sheet also quotes a historical source, save the character choices in the setting record and the relevant quotation and citation in a research record.

For a study sample, select its `books/学习样本/<书名>/` directory. When studying a work written here, use its existing `books/创作作品/<书名>/` directory. For research collected to write a particular book, select the receiving book. A saved excerpt should include its source, edition or date where known, and enough surrounding text to interpret it. Keep a retained source file such as a scan or map in that book's `资料/` directory. Create the directory when the first file needs it.

When reusing material, copy the selected file or passage, including any companion material it depends on. For a database record, read the original bytes with `records read REF` and save the text in the receiving book with `records save`, `--category research` and `--source` for attribution. A record containing references to other items needs the underlying items copied too, with local references in the new record. For a file, make a regular file copy and compare its digest with the source. The receiving book must remain readable after the supplying book is removed.

Use `study create ID --file SOURCE --sha256 DIGEST --start START --end END --genre GENRE --title TITLE --edition EDITION --question QUESTION --analyst A --analyst B --reviewer C --reviewer D`. Choose four distinct identities. Registration authenticates the file against the supplied digest and stores just the approved span. Coordinates count Unicode code points from zero, exclude an initial UTF-8 BOM, preserve CRLF, and exclude the end coordinate. Name an edition and source scope explicitly. `study catalog` lists registered scopes without revealing the prose.

1. Give each analyst the same question and the same source windows through `study window ID --actor A --start N --end M`. After the recipient confirms receipt and reading, register it with `study ack ID --actor A --window WINDOW --sha256 WINDOW_DIGEST`. Inspect `study coverage ID` to distinguish returned ranges from confirmed reading, compare analysts' individual ranges and find gaps. Acknowledgement records a reported observation. The tool cannot independently verify comprehension.
2. Each analyst freezes their own first response with `study observe ID --actor A --file RESPONSE --at N --quote QUOTATION`. The quotation must match the selected edition within that analyst's acknowledged range. `study exchange ID` opens after both first responses are frozen. Discuss differences and counterexamples. Keep conclusions within the source ranges actually read.
3. Record the resulting profile with `study synthesize ID --kind technique --file PROFILE` or `--kind style`. Each reviewer reads an assigned original window, acknowledges it, receives the profile and submits `study review ID --kind technique --revision R --actor C --verdict accept --file REPLY`. A reviewer can request changes using `revise`. The first review stays out of `study profile` until both reviews arrive. A changed profile creates a new revision.
4. Once both independent reviews accept a revision, `study adopt ID --kind technique --revision R --decision USER_DECISION_REFERENCE` records the user’s actual selection. The local coordinator supplies the genuine event reference. Raw research stays outside blind reader packets and is never inserted into the author's manuscript automatically.

## Finding the earlier scene

Use a stable session label for one author or editor working toward a particular chapter. For chapter 10, try `scene find --session author-ch10 --before 10 '从炉泥里拿出来的东西'`. The offline index finds overlapping words and Chinese character pairs and can use author-supplied aliases. It indexes the selected earlier revisions locally. An exact source passage enters the author’s context when the tool returns it. `--limit N` changes the number of candidate locations. Continue only while the question needs more evidence.

The candidates include chapter, revision, source SHA-256, scene number, original text and a half-open character range. To read a whole scene, use `scene open --session author-ch10 --before 10 --chapter 7 --revision 1 --scene 2`. Headings, standalone Chinese section numbers and scene dividers mark boundaries. An unmarked chapter is one scene. Add a useful description to a particular revision using `scene alias '柜台上的木牌' --chapter 7 --revision 1 --scene 2`. Search again if the selected version changes.

Use `scene check --session editor-ch10 --before 10 --draft FILE` to look for consequential retrospective statements. The checks use time and recall cues and return possible source scenes alongside the draft sentences. An editor can include an additional exact draft passage using `--claim TEXT`. A missing passage can mean new action, a character's belief or deliberate ambiguity. The editor decides what the manuscript asserts and whether it should change. Lexical search can miss a paraphrase without shared terms or a matching alias.

`scene usage --session author-ch10` lists searches, expansions, source coordinates, gross and distinct returned characters and UTF-8 bytes. Repeated expansions count toward gross usage. Distinct ranges merge only within the same chapter revision. Telemetry covers material returned by the scene tools. The previous chapter supplied by `context`, host transport, attention, caching and provider usage require separate evidence.
