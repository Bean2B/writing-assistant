# Work on a book

When invoked outside the Writing Assistant workspace, resolve this skill directory's symlink and locate the project root two levels above the real `SKILL.md` directory. Use that root for the launcher and the default `books/` shelf. Honor any book directory the user selected.

Use the repo's `scripts/writing-assistant --book DIR` launcher. Select the book bound to the workspace or named by the user and check its title with `status`. Use `books/创作作品/<书名>/` for a work written here and `books/学习样本/<书名>/` for a book collected as a study sample. Name the directory after the book as titled, including Chinese punctuation where the filesystem allows it. Use Chinese for a Chinese book’s chapter and volume titles, notes, and files or folders created for the book. Keep CLI identifiers, required filenames and original source citations exact. When studying an authored work, use its existing directory. Use `init TITLE` for a new title. Keep trial drafts, continuations, revisions, plans, reader replies and assessments with the same book.

For a new work, run `prepare "USER REQUEST" --phase plan-book` with the actual request. The [opening brief](../../templates/book/opening-brief.md) supplies the structure defaults. Choose the unspecified story details yourself unless the user wants to decide them. Keep the brief with the book using `records save opening-brief` (see the [CLI example](../../README.md#start-writing)). If the user asked for prose, continue into the requested chapters. In a fresh author session, use `records history opening-brief` and read the latest ref if present. A later explicit instruction takes precedence.

Read supplied character sheets, setting references and writing instructions in place. Distill the applicable decisions into the receiving book's outline or setting record, using its current parent when saving a revision. Preserve constraints, exceptions and unresolved alternatives, and distinguish the user's choices from the author's additions. Use `records save NAME --stdin` with the synthesized text. Keep the supplied document and its verbatim text out of the book, including `资料/`, record bodies and task prompts.

Retain source text when a literary passage or factual claim needs evidence. For a mixed document, extract the relevant evidence with its attribution and organize the creative decisions separately. Use a book-local research record for a passage, or `资料/` for a source file needed in context. If another book needs that evidence, give it an independent copy with its source and edition. Keep a sample book's studied passages and reading notes with that title.

For “请续写《书名》”, choose the next chapter from the book's status, then request `context N`. It supplies the whole preceding manuscript, its draft/adopted state and active author notes. Earlier scenes are available using `recall --before N TERM`, or `read N --revision R` for the exact source. Start from a concrete question, try distinctive words from the text, and expand when the answer requires it. Stop when the evidence answers the question. Search results are literal passages. An empty result leaves the question open.

Use source-linked `fact` notes for things the text shows. The quote carries the evidence and the annotation explains its relevance. A character's guess remains that character's guess. Record a plan with `intent`, a missing answer with `open`, or a deliberately delayed reveal with `hold`. Recheck stale notes in `notes_for_review` before using them. Close resolved notes by ID. A source can go stale when the selected manuscript changes. Prefer a short cue and the original scene to a second running synopsis.

In Lotus mode, use the [volume and turn outline](../../templates/book/writing-assistant-outline.md) when planning a volume or a major turn. The [scene worksheet](../../templates/book/scene-input.md) can help with a difficult scene. Consult the [cultivation note](references/genre-notes/cultivation.md) for that genre. Research a concrete question of language, material culture or custom when it affects credibility. Keep approximate lengths and chapter counts flexible when drafting or resuming. Choose chapter breaks for the scene and respect any delivery limit the user explicitly sets.

Before saving, check the important physical action, the protagonist's choice and consequential claims about earlier events. Preserve emotional echoes that serve the reader. Finish each new or revised chapter with its own [chapter card](../../docs/world-and-records.md#chapter-dossiers). Store a short summary and at least one meaningful observation with an exact quote. Include changes in ability, possessions, relationships or surroundings when they matter. Keep a character's interpretation, intentions, unresolved questions and deliberate omissions distinct. A quiet chapter can record a single observation.

Use `save N --file manuscript.md --card card.json` to save both together. If the manuscript arrived alone, use `chapter N --revision R --card -` with the card JSON on stdin. With a desktop book tool, supply the JSON as `input_text` in that second call. Use the returned revision and digest for every reader and follow the [reader protocol](references/readers.md). Distinguish missed intended meaning from a deliberately open question. Adoption uses `adopt N --revision R` only following the user's decision about that manuscript.

For a long-range callback, use `scene find --before N --session LABEL QUESTION` and expand the relevant scene. Use `scene check` when a consequential claim depends on old events. An editor resolves conflicting evidence in context. Find tools, measurements and study authorization in [study and recall](../../docs/study-and-recall.md).

Use [Creative Records, preparation and the World Sandbox](../../docs/world-and-records.md) for explicit author materials, actor knowledge and simulated decisions. A world projection becomes available to a writer only through a deliberately selected record. Use [reader trials](../../docs/reader-trials.md) for continuous or comparative blind reads. Use the [task runtime](../../docs/task-runtime.md) for an authorized provider or desktop workflow. Select an existing session through the host when a particular reader must continue.
